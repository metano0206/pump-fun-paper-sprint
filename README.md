A momentum + volume-confirmation paper-trading bot for pump.fun. It buys only when recent trades show real buyer demand behind a rising price, keeps positions small (about 0.06 SOL, at most 4 open), exits on fixed rules (take profit, stop loss, trailing stop, maximum holding time), and rotates across coins so it keeps meeting new markets instead of marrying one.

## Run it

The grader runs it as:

```sh
python3 -P -s main.py
```

with `vendor/makefun_bot.py` (the official Python SDK shim from the competition kit) next to it. To check it locally with the kit:

```sh
node cli/makefun.mjs grade-local --kit <kit dir> --bot <this repo> --driver process
```
